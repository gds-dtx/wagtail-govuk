{% comment %} The question box: a one-line box for a question, posted to /ask/, which shows the closest matches on the site. Posted rather than put in the address, so the question is not kept in the address bar, the browser's history or any access log on the way. Nothing at all while Ask is off. Laid out like GOV.UK's own large search box: the box and a square button with a magnifier, side by side, two thirds of the width of a full-width page (main.css, .app-question-box). No text above or below it: its hint is the placeholder, greyed inside it until something is typed, and the box's label and the button's text are read out by screen readers but not shown (a placeholder is no name for a box: it is not reliably read out, and it goes as soon as anything is typed). The /ask/ page the question goes to carries the note not to include personal information. Sent empty, it is not sent: main.js (setQuestionBoxes) shows the error message under the box instead ("empty_error"). Without JavaScript, /ask/ shows it ("error"), and any other error about the question, with the question again in the box ("question"). With "lead", for AI search's search area (includes/ask_search.html): the label is shown, above the box, as the area's lead text ("lead_heading": as the page's heading, on /ask/ without a combined hero), and the note not to include personal information is under it. With "inverse", in a combined hero's brand-colour band: no border on the box, and the lead, the note and any error message in white. {% endcomment %} {% if ask_on %}
